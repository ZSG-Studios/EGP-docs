SuperpositionProperty
=====================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A typed, quantized gameplay property replication rule.

.. rst-class:: classref-introduction-group

Description
-----------

Created automatically from a :ref:`Superposition<class_Superposition>` target's Replicate checkbox. The server and client must use identical enabled property order, names, types and quantization. Only bool, int, float, String and Vector3 are supported; objects, resources and arbitrary containers cannot replicate.
