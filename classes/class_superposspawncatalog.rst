SuperposSpawnCatalog
====================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Bounded allowlist of schema and resource pairs for a spawner.

.. rst-class:: classref-introduction-group

Description
-----------

Holds at most 64 :ref:`SuperposSpawnEntry<class_SuperposSpawnEntry>` resources. :ref:`SuperposSpawner.start()<class_SuperposSpawner_method_start>` captures an immutable native snapshot, so later edits to this resource do not change an attached receiver. Validation never instantiates a scene, resolves a node path, inspects a script property list or executes a gameplay getter. Script-extended catalogs and entries are rejected.
