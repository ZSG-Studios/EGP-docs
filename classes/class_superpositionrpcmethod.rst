SuperpositionRPCMethod
======================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A typed, permission-checked network method rule.

.. rst-class:: classref-introduction-group

Description
-----------

One explicit RPC allowlist entry for :ref:`SuperpositionRPC<class_SuperpositionRPC>`. Select a stable ID, exact target method name, sender permission, argument Variant types and call-rate limit. Matching peers must use the same complete method schema. Arbitrary method names received over the network are never invoked.
