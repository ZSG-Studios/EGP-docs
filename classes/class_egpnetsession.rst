EGPNetSession
=============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Native Yojimbo transport and server-authoritative entity replication.

.. rst-class:: classref-introduction-group

Description
-----------

Configure a session, listen as a server, or join using an encrypted connect token. Direct address joins require explicitly enabled loopback development mode. Call poll regularly on the creating thread. Commands expose bounded raw messages, entity replication, peer lists and interest filtering. The EGPNet GDScript helper adds named handlers and registered scene factories. Server peer identifiers refer to a connection generation; reconnects do not inherit ownership.

.. rst-class:: classref-method

:ref:`Variant<class_Variant>` **command**\ (\ operation\: :ref:`StringName<class_StringName>`, arguments\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_EGPNetSession_method_command>`

Performs a low-level operation. All operations belong to the creating thread. Before configuration, returns :ref:`@GlobalScope.ERR_UNCONFIGURED<class_@GlobalScope_constant_ERR_UNCONFIGURED>`. Unknown operation names return :ref:`@GlobalScope.ERR_INVALID_PARAMETER<class_@GlobalScope_constant_ERR_INVALID_PARAMETER>`.

\ ``peers``: returns an :ref:`Array<class_Array>` of dictionaries containing ``peer_id``, ``client_id``, and ``ping_ms``. Server peer IDs identify connection generations; clients use peer ``0``.

\ ``entities``: returns an :ref:`Array<class_Array>` of dictionaries containing ``entity``, ``revision``, ``tick``, ``kind``, ``authority_peer``, and ``state`` (:ref:`PackedByteArray<class_PackedByteArray>`).

\ ``entity``: argument ``entity``; returns the same dictionary fields for one handle, or an empty dictionary if absent. Copies only the requested entity, preserving immediate mutation readback without copying the whole world. Available to every language through :ref:`command()<class_EGPNetSession_method_command>`.

\ ``spawn``: server-only; arguments ``kind`` (nonnegative integer), ``state`` (:ref:`PackedByteArray<class_PackedByteArray>`, at most 4096 bytes, default empty), and ``authority_peer`` (default ``-1`` for server ownership). Returns a dictionary with ``error`` and ``entity``; use the entity handle only when the error is :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>`. A client owner must be a current connected peer.

\ ``update_entity``: server-only; arguments ``entity`` and ``state`` (at most 4096 bytes). Returns an :ref:`Error<enum_@GlobalScope_Error>`; changes are replicated by subsequent polling.

\ ``despawn``: server-only; argument ``entity``. Returns an :ref:`Error<enum_@GlobalScope_Error>`.

\ ``disconnect``: argument ``peer``. A server disconnects that client; a client uses ``0`` to stop. Returns an :ref:`Error<enum_@GlobalScope_Error>`.

\ ``set_visible``: server-only; arguments ``entity``, ``peer``, and ``visible`` (Boolean, default ``true``). Returns an :ref:`Error<enum_@GlobalScope_Error>`. Hiding removes that entity from the selected client's replicated view; showing restores its current state.

\ ``set_replication_priority``: server-only; integer arguments ``entity`` and ``priority`` (1 to 16). Returns an :ref:`Error<enum_@GlobalScope_Error>`. Changes the weighted service preference for queued gameplay state while preserving waiting lower-priority flows. Baseline creation remains independent of update priority.

\ ``set_entity_delta_replication``: server-only; exact integer ``entity`` and Boolean ``enabled`` arguments. Opts one native entity into acknowledged-baseline byte patches. Default is full-state replication. A baseline advances only after acknowledgment, so skipped/coalesced updates never create a chained dependency on an unsent revision. Join, reconnect, interest re-entry, changed state length, nonbeneficial patches and exhausted retained snapshot capacity use a full frame. Acknowledged and pending snapshots are bounded to 1 MiB per peer; disabling the policy releases retained snapshots. Returns an :ref:`Error<enum_@GlobalScope_Error>`.

\ ``set_peer_replication_budget``: server-only; integer arguments ``peer`` and ``bytes_per_second``. Zero disables the gameplay update subbudget; positive rates must not exceed the existing session byte quota. The token bucket allows a burst of ``max(rate, 4160)`` envelope bytes, so a maximum-sized state can fit. Initial/new membership baselines and teardown bypass this update subbudget, but remain subject to the existing transport quotas. This measures admitted gameplay envelopes, not UDP or retransmission bytes. Returns an :ref:`Error<enum_@GlobalScope_Error>`. Policies expire with the connection generation.

\ ``replication_peer_statistics``: argument ``peer``; returns a server-side dictionary with ``bytes_per_second``, ``available_bytes``, ``sent_updates``, ``sent_bytes``, and ``budget_deferrals``, plus ``delta_updates``, ``delta_bytes_saved``, ``full_state_updates`` and ``baseline_bytes``. The latter counts retained acknowledged and pending full snapshots; delta/full counters include membership baselines, while sent_updates and sent_bytes exclude membership creation. Missing peers, clients and wrong-thread calls return an empty dictionary. Counts exclude membership creation/removal; deferrals count scheduling attempts that could not admit the next update.

\ ``send_packet``: arguments ``peer``, ``payload`` (:ref:`PackedByteArray<class_PackedByteArray>`), ``channel`` (0 to 3, default 0), and ``delivery`` (2 for reliable ordered, 4 for unreliable unordered, default 2). Payload limits are 4096 and 900 bytes respectively. Returns an :ref:`Error<enum_@GlobalScope_Error>`; the receiver emits :ref:`packet_received<class_EGPNetSession_signal_packet_received>`.

Server-only operations return :ref:`@GlobalScope.ERR_UNAUTHORIZED<class_@GlobalScope_constant_ERR_UNAUTHORIZED>` on clients. Missing entities or peers return :ref:`@GlobalScope.ERR_DOES_NOT_EXIST<class_@GlobalScope_constant_ERR_DOES_NOT_EXIST>`. Use :ref:`send_application()<class_EGPNetSession_method_send_application>` for the higher-level EGPNet helper's encoded messages.

.. _class_EGPNetSession_method_configure:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **configure**\ (\ options\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_EGPNetSession_method_configure>`

Initializes this session on its creating thread. Returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>` on success, :ref:`@GlobalScope.ERR_ALREADY_IN_USE<class_@GlobalScope_constant_ERR_ALREADY_IN_USE>` if already configured, or :ref:`@GlobalScope.ERR_INVALID_PARAMETER<class_@GlobalScope_constant_ERR_INVALID_PARAMETER>` for unknown keys, incorrect types, or out-of-range values. Configuration survives :ref:`stop()<class_EGPNetSession_method_stop>`; create another **EGPNetSession** to change it.

Accepted ``options`` keys and defaults:

\ ``game_protocol = "egp-game-v1"`` and ``simulation_fingerprint = "script-state-v1"``: nonempty strings of at most 256 UTF-8 bytes. These and ``tick_rate`` must match across peers.

\ ``tick_rate = 60``: integer from 1 to 240. ``max_players = 32``: integer from 1 to 64. ``max_entities = 1024``: integer from 1 to 4096.

\ ``messages_per_second = 1000``: integer of at least 32. ``bytes_per_second = 4194304``: integer of at least 8192. These bound each peer's outgoing admission and incoming delivery in separate one-second windows. Outgoing quota exhaustion returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>`; valid incoming bursts wait in bounded queues and channels advance in rounds. Byte charges estimate payload plus 64 bytes for full entity states, 72 bytes for delta states or 32 bytes for other messages, excluding UDP headers, fragmentation and retransmissions. Incoming delivery quotas do not cap all transport decoding work or replace gameplay abuse policies. Malformed or unauthorized envelopes still cause rejection; sustained valid excess traffic can exhaust transport queues.

\ ``timeout_seconds = 5``: integer from 1 to 60. ``token_lifetime_seconds = 30``: integer from 1 to 120.

\ ``allow_insecure_loopback = false``: Boolean enabling development joins only on literal ``127.0.0.1`` or ``::1``. In this mode the server must also bind to a literal loopback address.

\ ``private_key``: optional :ref:`PackedByteArray<class_PackedByteArray>` of exactly 32 bytes for server token signing. If omitted, a secure server generates its own random key. Do not log or send this key to clients.

\ ``simulated_loss = 0``: percentage from 0 to 100. ``simulated_latency_ms = 0`` and ``simulated_jitter_ms = 0``: milliseconds from 0 to 5000. All three accept finite integers or floats and apply to this session's outgoing network traffic.

.. _class_EGPNetSession_method_poll:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **poll**\ (\ ) :ref:`🔗<class_EGPNetSession_method_poll>`

Receives packets, advances transport time, emits connection/message signals, runs accumulated fixed simulation ticks, and sends queued packets. Call regularly on the creating thread, including while connecting. Returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>` for a different thread or recursive polling and :ref:`@GlobalScope.ERR_UNCONFIGURED<class_@GlobalScope_constant_ERR_UNCONFIGURED>` before :ref:`configure()<class_EGPNetSession_method_configure>`. Signal handlers execute synchronously on this thread. Calling :ref:`stop()<class_EGPNetSession_method_stop>` inside a handler defers teardown until polling completes.

Client simulation ticks begin after the authoritative baseline is complete and the session enters ``Connected``. Transport polling continues while ``Connecting`` or ``Synchronizing``; this waiting time does not advance the simulation clock. Server ticks begin after :ref:`listen()<class_EGPNetSession_method_listen>`. At most eight fixed ticks run per poll. If accumulated simulation time exceeds 0.5 seconds, emits :ref:`diagnostic<class_EGPNetSession_signal_diagnostic>`, stops the transport, clears session entities and resets simulation ticks, and returns :ref:`@GlobalScope.FAILED<class_@GlobalScope_constant_FAILED>`. This protects the simulation from an unbounded catch-up; it does not silently skip time or automatically reconnect. After polling returns, the application must resynchronize through fresh admission and a new authoritative baseline. For token connections, obtain a fresh token before calling :ref:`connect_token()<class_EGPNetSession_method_connect_token>` again. High-level language facades may require closing and reconfiguring their wrapper first. Keep recovery out of synchronous poll callbacks. Servers must restore authoritative game state explicitly; the session does not provide automatic persistence.

|void| **stop**\ (\ ) :ref:`🔗<class_EGPNetSession_method_stop>`

Configuration and identifier generations are retained so this session can :ref:`listen()<class_EGPNetSession_method_listen>` or connect again without stale identifiers aliasing new objects.
