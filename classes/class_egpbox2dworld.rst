EGPBox2DWorld
=============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Explicit fixed-tick Box2D simulation with stable entity identifiers, every Box2D feature and local rollback.

.. rst-class:: classref-introduction-group

Description
-----------

The 2D counterpart of :ref:`EGPBox3DWorld<class_EGPBox3DWorld>`. Owns a Box2D world independent of the scene physics server: call :ref:`configure()<class_EGPBox2DWorld_method_configure>`, queue commands, then call :ref:`step_tick()<class_EGPBox2DWorld_method_step_tick>` once per simulation tick. Commands execute in entity ID and sequence order; world commands run after body commands, joints after both. Use one constructing thread for every call.

Every Box2D feature is available through Dictionaries of named fields: bodies with any number of circle, capsule, box, polygon, segment and chain shapes and their materials, filters and events; every joint type; forces, torques, impulses and wind; world settings and explosions. Readback, per-step events and queries map Box2D shapes back to entity and shape index. Snapshots restore in place and keep every identity. They hold solver state for trusted local history on a compatible build only; never restore bytes received from a peer.

.. _class_EGPBox2DWorld_method_configure:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **configure**\ (\ tick_rate\: :ref:`int<class_int>` = 60, substeps\: :ref:`int<class_int>` = 4, worker_count\: :ref:`int<class_int>` = 1, gravity\: :ref:`Vector2<class_Vector2>` = Vector2(0, 980)\ ) :ref:`🔗<class_EGPBox2DWorld_method_configure>`

Creates the Box2D world once. Lengths are in Box2D length units, which EGP sets to ``physics/box_2d/pixels_per_meter`` for the whole process, so worlds use the same pixel scale as 2D scenes (the default gravity is Godot's 980 pixels per second squared, Y down). The units are part of :ref:`get_simulation_fingerprint()<class_EGPBox2DWorld_method_get_simulation_fingerprint>` and of snapshots. Worker counts above 1 run solver tasks on the engine :ref:`WorkerThreadPool<class_WorkerThreadPool>`; results do not depend on scheduling.

.. _class_EGPBox2DWorld_method_queue_create_body:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **queue_create_body**\ (\ entity_id\: :ref:`int<class_int>`, sequence\: :ref:`int<class_int>`, body\: :ref:`Dictionary<class_Dictionary>`, shapes\: :ref:`Array<class_Array>`\[:ref:`Dictionary<class_Dictionary>`\]\ ) :ref:`🔗<class_EGPBox2DWorld_method_queue_create_body>`

Creates a body from any Box2D body fields (see :ref:`get_field_names()<class_EGPBox2DWorld_method_get_field_names>` with ``"body"``) and attaches ``shapes`` as shape indices 0, 1, 2 and so on. ``type`` accepts ``"static"``, ``"kinematic"``, ``"dynamic"`` or 0-2; ``rotation`` is an angle in radians. ``fast_rotation`` applies at creation only.

Each shape is a :ref:`Dictionary<class_Dictionary>` with a ``type`` (\ ``"circle"``, ``"capsule"``, ``"box"``, ``"polygon"``, ``"segment"``, ``"chain"``), geometry keys and any shape fields (\ ``friction``, ``restitution``, ``rolling_resistance``, ``tangent_speed``, ``density``, ``category``, ``mask``, ``group``, ``sensor``, ``contact_events`` and so on). Geometry keys: ``radius`` (circle, capsule, or rounding of box and polygon), ``center`` and ``angle`` (local placement), ``half_height`` or ``point_a``/``point_b`` (capsule, segment), ``half_extents`` (box), ``points`` (polygon hull of up to 8 points; chain points) and ``materials`` (chains: an :ref:`Array<class_Array>` with one material Dictionary per segment: points for a loop, points minus 3 for an open chain), ``loop`` (chains are one-sided segments from 4 points or more; an open chain's first and last points are ghost vertices).

::

    world.queue_create_body(3, 0, {"type": "dynamic", "position": Vector2(0, 4), "bullet": true},
            [{"type": "capsule", "radius": 0.3, "half_height": 0.5, "friction": 0.2},
            {"type": "box", "half_extents": Vector2(0.2, 0.1), "center": Vector2(0, 0.9), "angle": 0.3}])

.. _class_EGPBox2DWorld_method_queue_joint:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **queue_joint**\ (\ joint_id\: :ref:`int<class_int>`, sequence\: :ref:`int<class_int>`, type\: :ref:`String<class_String>`, body_a\: :ref:`int<class_int>`, body_b\: :ref:`int<class_int>`, fields\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_EGPBox2DWorld_method_queue_joint>`

Creates any Box2D joint: ``"distance"``, ``"filter"``, ``"motor"``, ``"prismatic"``, ``"revolute"``, ``"weld"`` or ``"wheel"``. Common fields: ``anchor_a``, ``rotation_a``, ``anchor_b``, ``rotation_b`` (body-local frames; prismatic and wheel joints slide along the frame's X axis), ``collide_connected``, ``force_threshold``, ``torque_threshold``, ``constraint_hertz``, ``constraint_damping_ratio``. Type fields use Box2D's names in snake case, for example ``length``, ``enable_spring``, ``hertz``, ``enable_limit``, ``lower_angle``, ``enable_motor``, ``motor_speed``, ``max_motor_torque``, ``lower_translation``. Joints are created after the batch's body commands.
