SuperposUInt64
==============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Native unsigned integer helpers preserving all 64 bits.

.. rst-class:: classref-introduction-group

Description
-----------

Compiled into the EGP engine through its native Superpos module. Full-width unsigned values use signed opaque Variant bits in GDScript and unsigned native metadata in generated C# and C++ bindings.
