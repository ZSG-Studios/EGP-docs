.. _class_Box2DDirectSpaceState2D_method_cast_shape:

.. rst-class:: classref-method

:ref:`Dictionary<class_Dictionary>` **cast_shape**\ (\ parameters\: :ref:`PhysicsShapeQueryParameters2D<class_PhysicsShapeQueryParameters2D>`\ ) :ref:`🔗<class_Box2DDirectSpaceState2D_method_cast_shape>`

Sweeps the shape described by ``parameters`` along its motion and returns the nearest hit as a :ref:`Dictionary<class_Dictionary>`, or an empty dictionary if there is no hit. Keys are ``point`` (:ref:`Vector2<class_Vector2>`), ``destination`` (the query origin at the hit fraction), ``normal`` (:ref:`Vector2<class_Vector2>`), ``shape`` (collider shape index), ``rid`` (:ref:`RID<class_RID>`), ``collider_id``, and ``collider`` when a scene object exists. Honors the query collision mask, body/area flags, exclusions, and margin. Use a valid non-null query with a valid shape RID; access the world's direct state during the physics frame.

:ref:`Array<class_Array>`\[:ref:`Dictionary<class_Dictionary>`\] **cast_shape_all**\ (\ parameters\: :ref:`PhysicsShapeQueryParameters2D<class_PhysicsShapeQueryParameters2D>`, max_results\: :ref:`int<class_int>`\ ) :ref:`🔗<class_Box2DDirectSpaceState2D_method_cast_shape_all>`

Sweeps the query shape along its motion and returns up to ``max_results`` hit dictionaries ordered by travel fraction. Dictionary fields match :ref:`cast_shape()<class_Box2DDirectSpaceState2D_method_cast_shape>`. A nonpositive result limit or no hits returns an empty typed array. Supply a valid non-null ``parameters`` with a valid shape RID and query during the physics frame.
