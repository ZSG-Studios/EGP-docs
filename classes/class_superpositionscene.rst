SuperpositionScene
==================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

An allowlisted scene with a stable network prefab identifier.

.. rst-class:: classref-introduction-group

Description
-----------

One locally trusted scene in a :ref:`SuperpositionSpawner<class_SuperpositionSpawner>` allowlist. Assign a unique numeric :ref:`prefab_id<class_SuperpositionScene_property_prefab_id>` and a :ref:`PackedScene<class_PackedScene>` on every peer. Network messages identify this local resource by ID; they never request an arbitrary resource path. The spawner compares the complete scene schema fingerprint before exposing replicated instances.
