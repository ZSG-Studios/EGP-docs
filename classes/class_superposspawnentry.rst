SuperposSpawnEntry
==================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Local Inspector authoring of one admitted spawn resource.

.. rst-class:: classref-introduction-group

Description
-----------

Maps one registered schema to a trusted local :ref:`PackedScene<class_PackedScene>` and at most 64 field projections. Network input selects only this numeric resource ID; it never supplies a scene path, script, method or property name. Full-width unsigned identifiers use signed opaque Variant bits in GDScript and unsigned native metadata in generated C# and C++ bindings.
