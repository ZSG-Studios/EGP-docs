SuperpositionWorld
==================

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Inspector session setup and lifecycle for Superposition.

.. rst-class:: classref-introduction-group

Description
-----------

Owns and polls one native :ref:`EGPNetSession<class_EGPNetSession>` for a scene subtree. Add this node above :ref:`Superposition<class_Superposition>` and :ref:`SuperpositionSpawner<class_SuperpositionSpawner>` nodes to let them discover the session automatically. Select matching protocol, simulation fingerprint, tick rate and capacities in the Inspector. For a local test, enable :ref:`allow_insecure_loopback<class_SuperpositionWorld_property_allow_insecure_loopback>`, choose the server or local client :ref:`role<class_SuperpositionWorld_property_role>`, and enable :ref:`auto_start<class_SuperpositionWorld_property_auto_start>`. For authenticated clients, obtain a server-issued token through your application's admission service and call :ref:`join_token()<class_SuperpositionWorld_method_join_token>`. Tokens and signing keys are supplied at runtime and are not Inspector properties. :ref:`stop()<class_SuperpositionWorld_method_stop>` releases the owned session; a later start creates a fresh session and child components rebind. Inspect :ref:`get_statistics()<class_SuperpositionWorld_method_get_statistics>` and :ref:`network_error<class_SuperpositionWorld_signal_network_error>` for failures.

:ref:`Error<enum_@GlobalScope_Error>` **join_loopback**\ (\ ) :ref:`🔗<class_SuperpositionWorld_method_join_loopback>`

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **join_token**\ (\ client_id\: :ref:`int<class_int>`, token\: :ref:`PackedByteArray<class_PackedByteArray>`, binding\: :ref:`String<class_String>` = "0.0.0.0"\ ) :ref:`🔗<class_SuperpositionWorld_method_join_token>`

Configures a session if needed and starts a secure asynchronous connection using a 2048-byte server-issued ``token`` for ``client_id``. ``binding`` selects the client socket address. Keep tokens private and obtain a fresh token after expiration or resynchronization. Wait for Connected; :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>` alone does not establish admission.
