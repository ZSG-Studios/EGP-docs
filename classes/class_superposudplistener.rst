SuperposUdpListener
===================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Single-port native UDP server socket shared by many Session associations.

.. rst-class:: classref-introduction-group

Description
-----------

Binds one UDP socket that carries every server-side association attached with :ref:`SuperposSession.configure_udp_listener()<class_SuperposSession_method_configure_udp_listener>`. Each client prefixes its datagrams with the connection ID it was admitted with (pass ``connection_id`` in the :ref:`SuperposSession.configure_udp()<class_SuperposSession_method_configure_udp>` transport profile); server replies carry no prefix. The connection ID routes and never authenticates: DTLS authenticates the peer with its admission key, and a changed client address (for example a NAT rebinding) receives outbound traffic only after it answers an encrypted path challenge. Datagrams without a prefix, with an unknown connection ID, or anything but a handshake before an association has a path are dropped without a reply or an allocation. Until an address is authenticated, bytes sent to it are limited to ``amplification_factor`` times the bytes received from it, and every association has its own bounded receive queue.

Connection IDs come from trusted admission, must be nonzero and must be unpredictable. Every attached Session keeps this listener alive until its network is closed. All methods are main-thread and owner-thread only.

.. _class_SuperposUdpListener_method_bind:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **bind**\ (\ address\: :ref:`String<class_String>`, port\: :ref:`int<class_int>`, configuration\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_SuperposUdpListener_method_bind>`

Binds a numeric IPv4 or IPv6 ``address`` and ``port`` (0 picks a free port; see :ref:`get_local_port()<class_SuperposUdpListener_method_get_local_port>`). The socket binds exclusively, so another process cannot bind the same address and port. Accepted integer keys are ``maximum_associations`` (1 through 4096, default 256), ``queue_datagrams`` (per association, 1 through 256, default 32), ``poll_quantum`` (datagrams drained per poll, 1 through 4096, default 256), ``amplification_factor`` (1 through 10, default 3) and ``receive_buffer_bytes`` (kernel receive buffer request, 0 keeps the system default, at most 64 MiB). Unknown keys return :ref:`@GlobalScope.ERR_INVALID_PARAMETER<class_@GlobalScope_constant_ERR_INVALID_PARAMETER>`; an address already in use returns :ref:`@GlobalScope.ERR_ALREADY_IN_USE<class_@GlobalScope_constant_ERR_ALREADY_IN_USE>` or :ref:`@GlobalScope.ERR_CANT_CREATE<class_@GlobalScope_constant_ERR_CANT_CREATE>`.
