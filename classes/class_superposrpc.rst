SuperposRpc
===========

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A registered typed RPC declaration of a schema.

.. rst-class:: classref-introduction-group

Description
-----------

Declared in :ref:`SuperposSchema.rpcs<class_SuperposSchema_property_rpcs>`. The wire names an RPC only by its numeric ID and a target object handle; it never carries a method, script, resource or property name. Calls are authorized at execution: on the authority against the live World (declared RPC, payload bound, authority epoch and :ref:`permission<class_SuperposRpc_property_permission>`, with the current ownership revision for Owner calls), and on a client only for a Ready replica whose schema declares the RPC.
