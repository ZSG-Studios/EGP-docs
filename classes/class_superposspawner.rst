SuperposSpawner
===============

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Native receiver spawner that projects canonical replicas into local scenes.

.. rst-class:: classref-introduction-group

Description
-----------

Attaches the bounded native replica receiver to a configured :ref:`SuperposSession<class_SuperposSession>` and instantiates scenes admitted by its :ref:`SuperposSpawnCatalog<class_SuperposSpawnCatalog>`. Canonical native state publishes atomically. Scene projection runs afterwards on the owner thread and is sequential: setters can observe a completed field prefix, and no atomic-scene claim is made. Every construction, setter and tree insertion revalidates native identities, the Session binding generation and a generation-checked projection ticket before continuing.

A leave received while construction is pending cancels that construction, and late callbacks cannot resurrect it. A bound replica that has not received its initial canonical state within the spawn readiness timeout (15 seconds by default) is marked timed out. If that state arrives later, canonical state is still applied, but the scene projection is held in the failed phase with a timeout error until :ref:`SuperposReplicaView.retry_projection()<class_SuperposReplicaView_method_retry_projection>` is called. Retirement invalidates the projection ticket before a scene node is deleted. When retirement reenters from the root's own constructor, setter or tree callback, deletion of that root is deferred until the callback has returned. Freeing an attached spawner without :ref:`stop()<class_SuperposSpawner_method_stop>` transfers the Session's network to the native retirement queue. No scene destruction or user callback runs from the spawner destructor.

All methods are main-thread and owner-thread only. GDScript, C# and C++ call the same native ClassDB implementation.

.. _class_SuperposSpawner_method_project_pending:

.. rst-class:: classref-method

:ref:`Dictionary<class_Dictionary>` **project_pending**\ (\ ) :ref:`🔗<class_SuperposSpawner_method_project_pending>`

First marks pending constructions whose spawn readiness timeout has expired, then projects at most :ref:`projection_budget<class_SuperposSpawner_property_projection_budget>` pending replicas. Returns ``error``, ``timed_out`` (newly expired constructions), ``completed`` and ``failed``. Returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>` while a projection is already running or the spawner is stopping, and :ref:`@GlobalScope.ERR_UNCONFIGURED<class_@GlobalScope_constant_ERR_UNCONFIGURED>` when not started. After :ref:`start()<class_SuperposSpawner_method_start>`, the spawner also calls this from process notifications.

.. _class_SuperposSpawner_method_start:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **start**\ (\ receiver_config\: :ref:`Dictionary<class_Dictionary>`\ ) :ref:`🔗<class_SuperposSpawner_method_start>`

Snapshots the catalog, reserves every native row, proxy, slot and projection cell, and attaches the receiver to :ref:`session<class_SuperposSpawner_property_session>`. Accepted integer keys are ``authority_epoch``, ``connection_epoch``, ``replica_epoch``, ``peer``, ``maximum_active`` (at most 1000), ``maximum_transitions`` (at most 64), ``control_channel``, ``state_channel``, ``bulk_channel``, ``native_bytes`` (at most 64 MiB) and ``spawn_timeout_ms`` (1 through 60000, default 15000). Unknown keys, including atomic-scene requests, return :ref:`@GlobalScope.ERR_INVALID_PARAMETER<class_@GlobalScope_constant_ERR_INVALID_PARAMETER>`. The spawner must be inside the scene tree.

.. _class_SuperposSpawner_method_stop:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **stop**\ (\ ) :ref:`🔗<class_SuperposSpawner_method_stop>`

Cancels pending constructions, retires every projected node and detaches the receiver with bounded work. Returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>` when the receiver is fully detached, or when nothing is attached. Returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>` when called from a Session callback or while the Session is closing. The stop then remains requested: projection stays halted, canonical state keeps tracking the receiver, and the spawner retries the stop from process notifications. Old :ref:`SuperposReplicaView<class_SuperposReplicaView>` resources become stale.
