SuperpositionPrediction
=======================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Bounded native deterministic input prediction and authoritative reconciliation.

.. rst-class:: classref-introduction-group

Description
-----------

Records complete local simulation state through capture, restore, simulate and state-hash callbacks. Predict contiguous inputs locally, then accept authoritative input/hash frames. Corrections restore only a snapshot captured locally and replay the complete affected world. Solver snapshots are never imported from a network peer. Matching genesis, deterministic profiles and complete world input are game contracts. The Inspector Box3D prediction adapter delegates its replay history to this native class. GDScript, C# and C++ use the same journal and bounds.

History is limited to 512 pending ticks, 1 MiB per snapshot and 64 MiB total. Hash mismatch or callback failure disables prediction and emits resync_required. Reset captures a fresh trusted local baseline with a monotonic epoch. These methods belong to the creating thread and reject recursive calls. Presentation effects must be suppressed during replay.

.. _class_SuperpositionPrediction_method_accept:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **accept**\ (\ frames\: :ref:`Array<class_Array>`, epoch\: :ref:`int<class_int>` = -1\ ) :ref:`🔗<class_SuperpositionPrediction_method_accept>`

Validates an ordered batch of authoritative dictionaries with exact tick (:ref:`int<class_int>`), input (:ref:`PackedByteArray<class_PackedByteArray>`, at most 4096 bytes) and hash (16-character hexadecimal :ref:`String<class_String>`) fields. Fresh ticks must be contiguous after the last acknowledgment; older duplicates are ignored. ``epoch`` must match the configured epoch, or -1 to omit that check. Changed inputs restore a trusted locally captured state and replay all affected pending ticks with replay=true. Matching hashes advance the acknowledged baseline and release history. A hash or callback failure clears history, disables prediction and emits :ref:`resync_required<class_SuperpositionPrediction_signal_resync_required>`; recover from a trusted local baseline, not a peer-supplied solver snapshot.

.. _class_SuperpositionPrediction_method_configure:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **configure**\ (\ capture\: :ref:`Callable<class_Callable>`, restore\: :ref:`Callable<class_Callable>`, simulate\: :ref:`Callable<class_Callable>`, state_hash\: :ref:`Callable<class_Callable>`, initial_tick\: :ref:`int<class_int>` = 0, max_ticks\: :ref:`int<class_int>` = 128, max_state_bytes\: :ref:`int<class_int>` = 1048576, max_bytes\: :ref:`int<class_int>` = 33554432, epoch\: :ref:`int<class_int>` = 0\ ) :ref:`🔗<class_SuperpositionPrediction_method_configure>`

Installs four trusted local callbacks and captures the initial baseline. capture() returns a nonempty :ref:`PackedByteArray<class_PackedByteArray>`; restore(state) returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>`; simulate(tick, input, replay) returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>`; state_hash() returns a 16-character hexadecimal :ref:`String<class_String>`. Set ``max_ticks`` from 1 to 512, ``max_state_bytes`` from 1 to 1048576, and ``max_bytes`` up to 67108864 and at least one maximum state. Inputs, snapshots and the baseline count toward the history byte budget. ``initial_tick`` and ``epoch`` are nonnegative exact integers no greater than 2^53 minus one. Reconfiguration while ready returns :ref:`@GlobalScope.ERR_ALREADY_IN_USE<class_@GlobalScope_constant_ERR_ALREADY_IN_USE>`. All callbacks run synchronously on the creating thread; recursive journal calls return :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>`.

.. _class_SuperpositionPrediction_method_predict:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **predict**\ (\ tick\: :ref:`int<class_int>`, input\: :ref:`PackedByteArray<class_PackedByteArray>`\ ) :ref:`🔗<class_SuperpositionPrediction_method_predict>`

Simulates the next contiguous ``tick`` with a local input of at most 4096 bytes and journals its complete resulting state and hash. Returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>` before invoking game code if tick or byte capacity is insufficient. During ordinary prediction, simulate receives replay=false. Prediction does not send network input automatically.

.. _class_SuperpositionPrediction_method_reset:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **reset**\ (\ epoch\: :ref:`int<class_int>`, initial_tick\: :ref:`int<class_int>` = 0\ ) :ref:`🔗<class_SuperpositionPrediction_method_reset>`

Captures a new trusted local baseline after the caller restores its complete simulation world. ``epoch`` must strictly increase; ``initial_tick`` sets the new starting tick. Clears pending inputs and enables prediction only if capture and hash validation succeed. Epoch changes prevent old input batches from being accepted when the caller supplies the epoch to :ref:`accept()<class_SuperpositionPrediction_method_accept>`.
