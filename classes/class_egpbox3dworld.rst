EGPBox3DWorld
=============

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Explicit fixed-tick Box3D simulation with stable entity identifiers and local rollback.

.. rst-class:: classref-introduction-group

Description
-----------

Owns a Box3D world independent of the scene physics server. Call :ref:`configure()<class_EGPBox3DWorld_method_configure>`, queue commands, then call :ref:`step_tick()<class_EGPBox3DWorld_method_step_tick>` once per simulation tick. Commands execute in entity ID and sequence order. Use one constructing thread for every call. Body types are 0 (static), 1 (kinematic), and 2 (dynamic).

Every Box3D feature is available through Dictionaries of named fields: bodies with any number of shapes (sphere, capsule, box, convex hull, triangle mesh, height field) with their materials, filters and events (:ref:`queue_create_body()<class_EGPBox3DWorld_method_queue_create_body>`, :ref:`queue_set_body()<class_EGPBox3DWorld_method_queue_set_body>`, :ref:`queue_add_shape()<class_EGPBox3DWorld_method_queue_add_shape>`, :ref:`queue_set_shape()<class_EGPBox3DWorld_method_queue_set_shape>`); every joint type including EGP's 6DOF joint (:ref:`queue_joint()<class_EGPBox3DWorld_method_queue_joint>`, :ref:`queue_set_joint()<class_EGPBox3DWorld_method_queue_set_joint>`); forces, torques and impulses (:ref:`queue_apply()<class_EGPBox3DWorld_method_queue_apply>`); world settings (:ref:`queue_set_world()<class_EGPBox3DWorld_method_queue_set_world>`) and explosions (:ref:`queue_explode()<class_EGPBox3DWorld_method_queue_explode>`). Readback (:ref:`get_body()<class_EGPBox3DWorld_method_get_body>`, :ref:`get_shape()<class_EGPBox3DWorld_method_get_shape>`, :ref:`get_joint()<class_EGPBox3DWorld_method_get_joint>`, :ref:`get_world()<class_EGPBox3DWorld_method_get_world>`), per-step events (:ref:`get_events()<class_EGPBox3DWorld_method_get_events>`) and queries (:ref:`cast_rays()<class_EGPBox3DWorld_method_cast_rays>`, :ref:`cast_shape()<class_EGPBox3DWorld_method_cast_shape>`, :ref:`overlap_aabb()<class_EGPBox3DWorld_method_overlap_aabb>`, :ref:`overlap_shape()<class_EGPBox3DWorld_method_overlap_shape>`, :ref:`move_capsule()<class_EGPBox3DWorld_method_move_capsule>`) map Box3D shapes back to entity and shape index. :ref:`get_field_names()<class_EGPBox3DWorld_method_get_field_names>` lists the fields of each set.

Snapshots include the solver state and are only for trusted local history on a compatible build. Never restore bytes received from a peer. This class does not replace the physics of :ref:`RigidBody3D<class_RigidBody3D>` or :ref:`CharacterBody3D<class_CharacterBody3D>`.

Enable ``physics/box3d/audit_determinism`` before configuring a world to run a separate native mirror solver. Commands, fixed steps and trusted restores are repeated and their diagnostic hashes compared. Divergence fails closed with :ref:`@GlobalScope.ERR_INVALID_DATA<class_@GlobalScope_constant_ERR_INVALID_DATA>`. Object metadata ``box3d_audit_verified_steps``, ``box3d_audit_verified_boundaries`` and ``box3d_audit_hash_mismatches`` provide evidence. This diagnostic doubles solver work; it is disabled by default and does not implement remote prediction or establish cross-platform determinism.

.. _class_EGPBox3DWorld_method_queue_create_body:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **queue_create_body**\ (\ entity_id\: :ref:`int<class_int>`, sequence\: :ref:`int<class_int>`, body\: :ref:`Dictionary<class_Dictionary>`, shapes\: :ref:`Array<class_Array>`\[:ref:`Dictionary<class_Dictionary>`\]\ ) :ref:`🔗<class_EGPBox3DWorld_method_queue_create_body>`

Creates a body from any Box3D body fields (see :ref:`get_field_names()<class_EGPBox3DWorld_method_get_field_names>` with ``"body"``) and attaches ``shapes`` as shape indices 0, 1, 2 and so on. ``type`` accepts ``"static"``, ``"kinematic"``, ``"dynamic"`` or 0-2. Each shape is a :ref:`Dictionary<class_Dictionary>` with a ``type`` (\ ``"sphere"``, ``"capsule"``, ``"box"``, ``"hull"``, ``"mesh"``, ``"height_field"``, ``"compound"``), geometry keys and any shape fields (\ ``friction``, ``restitution``, ``density``, ``category``, ``mask``, ``sensor``, ``contact_events`` and so on). Geometry keys: ``radius``, ``center`` and ``rotation`` (local placement), ``half_height`` or ``point_a``/``point_b`` (capsule), ``half_extents`` (box), ``points`` and ``scale`` (hull), ``points``, ``indices`` and ``scale`` (mesh; collides with static bodies only), ``heights``, ``count_x``, ``count_z``, ``holes`` and ``scale`` (height field, placed by its body; static bodies only), ``children`` (baked compound for static bodies: an :ref:`Array<class_Array>` of sphere, capsule, box, hull and mesh Dictionaries, each with its own placement and material fields). Meshes and height fields take per-triangle or per-cell materials: ``materials`` (an :ref:`Array<class_Array>` of material Dictionaries, table indices 1 and up after the shape's own material 0) and ``material_indices`` (a :ref:`PackedByteArray<class_PackedByteArray>` with one index per triangle or cell).

    world.queue_create_body(7, 0, {"type": "dynamic", "position": Vector3(0, 4, 0), "bullet": true},
            [{"type": "capsule", "radius": 0.4, "half_height": 0.5, "friction": 0.2},
            {"type": "sphere", "radius": 0.3, "center": Vector3(0, 1.1, 0), "density": 0.5}])

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **queue_create_joint**\ (\ joint_id\: :ref:`int<class_int>`, sequence\: :ref:`int<class_int>`, kind\: :ref:`JointKind<enum_EGPBox3DWorld_JointKind>`, body_a\: :ref:`int<class_int>`, body_b\: :ref:`int<class_int>`, anchor_a\: :ref:`Vector3<class_Vector3>`, anchor_b\: :ref:`Vector3<class_Vector3>`, options\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_EGPBox3DWorld_method_queue_create_joint>`

    # Cloth: particle spheres linked by distance joints.
    world.queue_create_joint(1, 0, EGPBox3DWorld.JOINT_DISTANCE, 10, 11, Vector3.ZERO, Vector3.ZERO, {"length": 0.5})

    world.queue_create_joint(2, 0, EGPBox3DWorld.JOINT_PRISMATIC, 20, 21, Vector3.ZERO, Vector3.ZERO,

.. _class_EGPBox3DWorld_method_queue_joint:

.. rst-class:: classref-method

:ref:`Error<enum_@GlobalScope_Error>` **queue_joint**\ (\ joint_id\: :ref:`int<class_int>`, sequence\: :ref:`int<class_int>`, type\: :ref:`String<class_String>`, body_a\: :ref:`int<class_int>`, body_b\: :ref:`int<class_int>`, fields\: :ref:`Dictionary<class_Dictionary>` = {}\ ) :ref:`🔗<class_EGPBox3DWorld_method_queue_joint>`

Creates any Box3D joint: ``"distance"``, ``"spherical"``, ``"prismatic"``, ``"motor"``, ``"revolute"``, ``"weld"``, ``"wheel"``, ``"filter"``, ``"parallel"`` or ``"generic"`` (EGP 6DOF). Common fields: ``anchor_a``, ``rotation_a``, ``anchor_b``, ``rotation_b`` (body-local frames; prismatic, revolute and wheel joints use the frame's axes), ``collide_connected``, ``force_threshold``, ``torque_threshold``, ``constraint_hertz``, ``constraint_damping_ratio``. Type fields use Box3D's names in snake case, for example ``enable_limit``, ``lower_angle``, ``enable_motor``, ``motor_speed``, ``max_motor_torque``, ``suspension_hertz``, ``spin_speed``, ``cone_angle``.

Generic joints take one :ref:`Vector3<class_Vector3>` per PhysicsServer3D 6DOF parameter (x, y and z axes): ``linear_lower_limit``, ``linear_upper_limit``, ``angular_lower_limit``, ``angular_motor_target_velocity``, ``linear_spring_stiffness`` and so on, with flags ``enable_linear_limit``, ``enable_angular_limit``, ``enable_linear_spring``, ``enable_angular_spring``, ``enable_linear_motor`` and ``enable_angular_motor`` (a non-zero component enables that axis). Joints are created after the batch's body commands, so bodies and their joints can be created in the same tick.
