EGPNetSnapshotInterpolator
==========================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Bounded native snapshot presentation for replicated 3D entities.

.. rst-class:: classref-introduction-group

Description
-----------

Bounded presentation history for authoritative 3D snapshots: up to 32 samples per entity and 1024 entities. Submit accepted samples, advance once per render frame, then sample visible entities. Interpolates position and shortest-arc rotation; sparse updates use bounded linear and world-space angular velocity extrapolation. Correction offsets decay in presentation space while preserving transform scale. The global presentation clock never reverses or runs beyond the newest global snapshot during an outage. Explicit discontinuity epochs clear per-entity history for teleports or respawns and reject older epochs. Legacy samples without epochs retain the eight-unit teleport heuristic. An optional bounded adaptive delay margin absorbs sparse authoritative sample cadence. Methods belong to the creating thread. This helper never changes authoritative physics or establishes deterministic input prediction.

Sets timing and clears history. ``tick_rate`` is the shared authority tick frequency; ``delay_seconds`` sets the base buffer; ``max_extrapolation_seconds`` bounds sparse-entity extrapolation. A positive ``max_adaptive_delay_seconds`` enables a ceiling at least as large as the base delay; zero keeps the fixed buffer. Adaptation follows observed authoritative tick spacing, not RTT. Rejects invalid or nonfinite values without changing configuration.

.. _class_EGPNetSnapshotInterpolator_method_submit:

.. rst-class:: classref-method

:ref:`bool<class_bool>` **submit**\ (\ entity\: :ref:`int<class_int>`, tick\: :ref:`int<class_int>`, pose\: :ref:`Transform3D<class_Transform3D>`, velocity\: :ref:`Vector3<class_Vector3>`, discontinuity_epoch\: :ref:`int<class_int>` = -1, angular_velocity\: :ref:`Vector3<class_Vector3>` = Vector3(0, 0, 0)\ ) :ref:`🔗<class_EGPNetSnapshotInterpolator_method_submit>`

Accepts strictly increasing ``tick`` values for a positive ``entity``, with a finite ``pose``, ``velocity`` and world-space ``angular_velocity`` in radians per second. Angular speed is bounded to 1000 radians per second. Ticks and explicit epochs must be exact integers up to 2^53 minus one. ``discontinuity_epoch`` of -1 selects legacy behavior; a higher explicit epoch clears history/corrections, while lower epochs are rejected. Epoch changes do not permit the shared tick timeline to reverse. All entities must share the same authority tick timeline. Returns false for stale, invalid or capacity-exceeding samples.
