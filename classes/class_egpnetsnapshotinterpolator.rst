EGPNetSnapshotInterpolator
==========================

**Inherits:** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Bounded native snapshot presentation for replicated 3D entities.

.. rst-class:: classref-introduction-group

Description
-----------

Stores up to 32 snapshots for each of at most 1024 entities. Call :ref:`submit()<class_EGPNetSnapshotInterpolator_method_submit>` for accepted authoritative snapshots, :ref:`advance()<class_EGPNetSnapshotInterpolator_method_advance>` once per render frame, then :ref:`sample()<class_EGPNetSnapshotInterpolator_method_sample>` for visible entities. Playback never reverses or advances beyond the newest global snapshot during a network outage. Sparse entity updates use bounded velocity extrapolation; position and shortest-arc rotation corrections decay in presentation space while preserving transform scale. Position changes exceeding eight units clear the entity history as teleports. Methods are confined to the creating thread. Ticks must be between zero and 2^53 minus one. This component does not predict inputs, modify physics, or establish clock synchronization across peers.
