SuperposReplicaView
===================

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Immutable weak view of one received canonical replica.

.. rst-class:: classref-introduction-group

Description
-----------

Returned by :ref:`SuperposSpawner.get_replicas()<class_SuperposSpawner_method_get_replicas>`. It cannot be constructed directly. The view reads the receiver's canonical image through the shared typed decoder and never indexes the authoritative World. It holds only a weak Session identity, the receiver binding generation, the full handle and the complete replica key. After stop, detach, reattachment, incarnation reuse, ownership encoding reset or migration, an old view stays stale and every call returns an error, even when wire replica keys are reused. All calls are main-thread and owner-thread only.

:ref:`Error<enum_@GlobalScope_Error>` **call_rpc**\ (\ rpc_id\: :ref:`int<class_int>`, payload\: :ref:`PackedByteArray<class_PackedByteArray>`\ ) |const| :ref:`🔗<class_SuperposReplicaView_method_call_rpc>`

Sends the registered schema RPC ``rpc_id`` for this replica to the authority over the receiver's RPC channel. The replica must be canonical-ready and its schema must declare the RPC; ``payload`` may not exceed the declared maximum. A client is never the authority, so an Authority-permission RPC returns :ref:`@GlobalScope.ERR_UNAUTHORIZED<class_@GlobalScope_constant_ERR_UNAUTHORIZED>`, and an Owner-permission RPC returns it unless this peer owns the replica. The call carries the observed ownership revision; the authority authorizes it again when gameplay takes it. Returns :ref:`@GlobalScope.ERR_BUSY<class_@GlobalScope_constant_ERR_BUSY>` while eight sends are still awaiting delivery, and :ref:`@GlobalScope.ERR_UNAVAILABLE<class_@GlobalScope_constant_ERR_UNAVAILABLE>` for an undeclared RPC.

:ref:`Dictionary<class_Dictionary>` **read_fields**\ (\ fields\: :ref:`PackedInt64Array<class_PackedInt64Array>`\ ) |const| :ref:`🔗<class_SuperposReplicaView_method_read_fields>`

Decodes the listed registered field IDs from the current canonical image. On success the Dictionary contains ``error``, ``values`` keyed by field ID, ``revision``, ``owner``, ``ownership_revision``, ``canonical_ready``, ``binding_generation`` and ``handle``. Unknown or duplicate IDs return :ref:`@GlobalScope.ERR_INVALID_PARAMETER<class_@GlobalScope_constant_ERR_INVALID_PARAMETER>`. A stale view returns another :ref:`Error<enum_@GlobalScope_Error>` code.

.. _class_SuperposReplicaView_method_read_status:

.. rst-class:: classref-method

:ref:`Dictionary<class_Dictionary>` **read_status**\ (\ ) |const| :ref:`🔗<class_SuperposReplicaView_method_read_status>`

Returns ``error``, ``canonical_ready``, ``revision``, ``binding_generation``, ``handle`` and, while the spawner runtime is attached, ``scene``. The ``scene`` Dictionary reports ``scene_phase`` (\ ``"pending"``, ``"ready"``, ``"failed"`` or ``"retiring"``), ``completed_fields``, ``projection_error``, ``projected_revision`` and ``spawn_timed_out``. A replica whose initial state missed the spawn readiness timeout reports the failed phase with ``spawn_timed_out`` set. Canonical readiness and scene projection are reported separately.
