SuperpositionRPC
================

**Inherits:** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Allowlisted reliable remote calls for spawned gameplay objects.

.. rst-class:: classref-introduction-group

Description
-----------

Dispatches explicitly allowlisted reliable RPCs for scenes managed by :ref:`SuperpositionSpawner<class_SuperpositionSpawner>`. Set :ref:`spawner_path<class_SuperpositionRPC_property_spawner_path>` and add matching :ref:`SuperpositionRPCMethod<class_SuperpositionRPCMethod>` resources. The receiver verifies scene and method fingerprints, live target identity, sender permission, exact arguments and rates. Dispatch is deferred out of the transport callback and revalidates identity and schema, so queued messages cannot retarget a despawned instance or replacement session. The queue holds at most 256 calls and limits aggregate incoming calls to 128 per peer per second. RPCs do not provide automatic gameplay authorization or prediction.

:ref:`Error<enum_@GlobalScope_Error>` **send_rpc**\ (\ entity\: :ref:`int<class_int>`, method_id\: :ref:`int<class_int>`, arguments\: :ref:`Array<class_Array>` = [], peer\: :ref:`int<class_int>` = -1\ ) :ref:`🔗<class_SuperpositionRPC_method_send_rpc>`

Queues an allowlisted method call for a live membership ``entity``. ``arguments`` must exactly match the method schema. Clients send to the server; servers use -1 to broadcast to compatible peers or a live ``peer`` to target one recipient. Returns :ref:`@GlobalScope.OK<class_@GlobalScope_constant_OK>` when queued, not when dispatched or acknowledged. A broadcast can partially enqueue before a later recipient fails; avoid blindly retrying non-idempotent effects.
