EGP documentation
=================

Welcome to the documentation for **EGP**, ZSG-Studios' fork of Godot Engine.
Explore Box2D and Box3D physics, Superpos networking, and built-in C++ tools
alongside the familiar Godot editor and scene workflow.

.. raw:: html

   <div class="egp-start-grid">
     <a href="egp/getting_started.html"><strong>Get started</strong><span>Build EGP and set up your project.</span></a>
     <a href="egp/migration.html"><strong>Migrate a project</strong><span>Understand the changed physics and multiplayer APIs.</span></a>
     <a href="egp/index.html"><strong>Explore EGP systems</strong><span>Physics, networking, extensions and runtime reload.</span></a>
     <a href="classes/index.html"><strong>Browse the API</strong><span>The class reference generated from EGP sources.</span></a>

These pages use Godot's documentation theme and retain the upstream manuals
for common engine features. EGP's guides and class reference describe the
fork-specific changes. Read :doc:`egp/qualification` for the tested scope.
