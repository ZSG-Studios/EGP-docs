Getting started with EGP
========================

Build the editor and matching templates with native xmake. The active desktop
profile enables Superpos and its MbedTLS-backed UDP/DTLS foundation. Use the
SDKs generated by that editor; .NET compilation stays local.

Start with :doc:`migration`, :doc:`networking_reference`, :doc:`box2d`,
:doc:`box3d` and :doc:`cpp_extensions`. Automatic scene spawning/RPC and old
network helpers are retired; use explicit application projection and dispatch.
Check :doc:`qualification` before relying on a platform or runtime feature.
