Exporting for the Web
=====================

Web exports are unsupported in EGP. WebGL rendering is removed, and no RenderingDevice web backend is available.

Export rendered projects to a supported native platform, or use a headless dedicated server. See :ref:`doc_export_index`, :ref:`doc_renderers` and :ref:`doc_exporting_for_dedicated_servers`.
